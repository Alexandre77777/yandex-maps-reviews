# ⏱️ Проверка корректности и производительности

Проверка выполнена 2 октября 2026 года. Задача — получить тексты, даты и индивидуальные оценки отзывов одной организации, сохранить сведения о карточке и явно обозначить незавершённый сбор.

## 🧭 Условия и критерий сравнения

Windows 11; Python 3.11.7; Playwright 1.52.0; установленный Chromium 138. Один браузер, одна вкладка и одна карточка за раз. Внутренними потоками Chromium управляет сам браузер; дополнительный параллелизм сборщика не используется. GPU не применяется.

Для проверки без сети использовалась сохранённая публичная HTML-страница с 50 отзывами. Извлечённые поля HTML и DOM сравнивались с исходной реализацией на том же входе: точное равенство. Для текста после объединения допускается только удаление пробелов по краям, которое выполняет DOM-разборщик. Числа, даты, содержимое текстов и количество записей не сокращались ради ускорения.

SHA-256 `collect_yandex.py` на момент проверки: `55d35c732731274398e92f457403d541eb26ae37ed10c3e539deebe4da08c5ac`.

Медианы 10 повторений в одном процессе после подготовки входа. Чтение HTML с диска выполнялось заранее. Память разборщика измерялась отдельно через `tracemalloc`, чтобы измерение памяти не влияло на замер времени.

Пик памяти Python при разборе HTML: **1.221 МиБ**. Он не включает Chromium. Пиковый RSS всей группы процессов браузера не измерялся; ограниченный объём проверки не позволяет сделать вывод о памяти при больших очередях. Холодный запуск Chromium в отдельном замере: 0.340 секунды; это не полное время подготовки контекста и загрузки сайта.

Различия времени разбора и чтения DOM невелики; отдельный коэффициент ускорения не заявляется. Подтверждённое устранение лишней работы: браузер не запускается при полностью готовом кэше; отзывы с полным текстом из HTML не раскрываются повторно. У 24 из первых 50 отзывов HTML позволил получить текст целиком, хотя DOM первоначально показывал сокращённую версию.

## 🔄 Кэш, ресурсы и дальнейший объём

Кэш соответствует `schema_version = 1` и идентификатору организации. Готовность требует уникальных ключей, текста, даты, целой оценки 1–5 и отсутствия сокращений. Состояния ошибки и промежуточный `running` не считаются завершённым сбором. Возобновление открывает страницу заново и объединяет её содержимое с ранее сохранёнными текстами.

Сеть и ожидание новых карточек остаются основным ограничением. Для ориентира: N похожих карточек потребуют примерно N × время попытки плюс (N − 1) × межкарточная пауза и подготовка браузера. При паузе 20 секунд и наблюдавшихся 22,33–30,69 секунды на карточку 10 похожих карточек заняли бы примерно 6,7–8,1 минуты без повторов. Это оценка, а не подтверждённая пропускная способность очереди.

**Итог: ограниченная проверка пройдена; массовый сбор не проверен.** Дополнительные потоки, процессы, компиляция и GPU не устраняют ожидание сайта и в текущей конфигурации не нужны. Маршрутизация ресурсов Playwright отключает HTTP-кэш браузера; повторное использование относится к JSON с данными, а не к сетевому кэшу изображений и сценариев.

Перед увеличением очереди следует проверить небольшой пакет на целевом компьютере: время, потребление памяти всей группой процессов Chromium, коды ответов и полноту результатов. Изменение селекторов, версии браузера, формата страницы или масштаба требует повторной проверки затронутых этапов. При сохраняющемся 429, CAPTCHA или отказе в доступе очередь останавливается с сохранением прогресса.
